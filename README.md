# Healthcare IT Service Desk Dashboard

## Project Goal
Analyze a simulated healthcare IT service desk dataset to identify ticket-volume trends, recurring technical issues, resolution performance, escalation patterns, and user satisfaction.

## Tools
- SQL
- Microsoft Excel
- Power BI (dashboard design)
- Data validation and KPI reporting

## Dataset
1,200 simulated service desk tickets covering January-June 2026.

Fields include:
- Ticket ID
- Opened Date
- Department
- Issue Category
- Priority
- Device/Application
- Resolution Hours
- Escalated
- First Contact Resolution
- User Satisfaction
- Status

## Suggested Power BI Dashboard
KPI cards:
- Total Tickets
- Average Resolution Time
- First Contact Resolution %
- Escalation Rate %
- Average Satisfaction

Visuals:
1. Ticket volume by month
2. Tickets by department
3. Tickets by issue category
4. Average resolution time by priority
5. Escalation rate by department
6. User satisfaction by issue category

Recommended slicers:
- Date
- Department
- Priority
- Issue Category
- Device/Application

## Portfolio Story
Use the dashboard to identify where an IT department may need additional training, documentation, workflow improvements, or technical resources. Because the data is simulated, do not present the findings as actual hospital performance.
